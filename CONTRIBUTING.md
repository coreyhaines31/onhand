# Contributing

Use a feature branch, keep commits focused, and run `make lint` and `make test` before opening a pull request. Changes to native UI also need `make app` and verification in the running app. Website changes need `npm run lint`, `npm run typecheck`, and `npm run build` from `site/`.

Never use real clipboard history as a test fixture or attach it to issues. Use synthetic examples. Keep capture local and retain the first-run consent boundary.

Contributions are licensed under MIT. There is no copyright assignment or contributor license agreement. If future work needs a different licensing model, contributor rights must be addressed before accepting contributions under that model.
